# SQLite Viewer

A lightweight, cross-platform SQLite database browser and query tool built with Python and PySide6.

## Features

- **Database Management**
  - Open existing `.db` / `.sqlite` / `.sqlite3` files
  - Create new databases with interactive schema designer
  - Close and switch between databases seamlessly

- **Data Browsing**
  - Browse table data with pagination (50/100/250/500 rows per page)
  - View table structure (columns, types, constraints)
  - Double-click cells to view full value details (type, character count, UTF-8 bytes)
  - Sortable columns in data views

- **SQL Editor**
  - Write and execute custom SQL queries
  - Multi-statement execution support
  - Results displayed in interactive table
  - Keyboard shortcut: `Ctrl+Enter` to execute
  - Toggle visibility with `Ctrl+E` or View menu

- **Database Objects**
  - Tree navigation for Tables, Views, Indexes, Triggers
  - Double-click tables to view comprehensive details:
    - Column definitions with primary key highlighting
    - Index information
    - Foreign key relationships
    - CREATE SQL statement
  - Schema viewer for full database structure

- **Theme Support**
  - Light theme (Windows-style blue/white)
  - Dark theme (Catppuccin Mocha inspired)
  - Switch via View → Theme menu

- **User Interface**
  - Clean, modern design with Fusion style
  - Status bar showing database path and operation messages
  - Responsive layout with adjustable splitters

## Installation

### Prerequisites

- Python 3.8 or higher
- pip (Python package manager)

### Setup

1. Clone or download this repository

2. Create a virtual environment (recommended):
   ```bash
   python -m venv .venv
   ```

3. Activate the virtual environment:
   - **Windows**: `.venv\Scripts\activate`
   - **Linux/Mac**: `source .venv/bin/activate`

4. Install dependencies:
   ```bash
   pip install PySide6
   ```

## Usage

### Launch the Application

```bash
python main.py
```

### Creating a New Database

1. Go to **File → New Database...** (`Ctrl+N`)
2. Choose a save location and filename
3. The schema designer dialog will appear:
   - Add/remove tables using the left panel
   - Define columns with name, type, and constraints
   - Preview generated SQL in real-time
   - Click **Create** to build the schema, or **Skip** for an empty database

### Opening an Existing Database

1. Go to **File → Open Database...** (`Ctrl+O`)
2. Select your `.db`, `.sqlite`, or `.sqlite3` file
3. Browse the database objects in the left tree panel

### Browsing Data

- **Single-click** a table name to view its data
- Navigate pages using Previous/Next buttons
- Adjust page size from the dropdown (50–500 rows)
- **Double-click** any cell to see full value details

### Viewing Table Details

- **Double-click** a table or column in the tree to open the Table Details dialog
- View columns, indexes, foreign keys, and CREATE SQL across multiple tabs

### Executing SQL Queries

1. Press `Ctrl+E` or go to **View → Show SQL Editor**
2. Type your SQL query in the editor
3. Press `Ctrl+Enter` or click **Execute**
4. Results appear in the table below

### Changing Themes

Go to **View → Theme** and select:
- **Light** — Clean, bright interface
- **Dark** — Easy on the eyes, Catppuccin-inspired colors
